# Archived ledgers

An append-only ledger is never edited, so one that turns out to be unpublishable
is retired here rather than corrected. Nothing in this directory is deleted.

## canary-*-dev.sqlite3 (retired 2026-10-03)

Retired because sighting 1 in it is the operator's own `curl/8.5.0` probe,
recorded with `origin='organic'` by a build that stamped one process-wide origin
on every row. Mechanically a true sighting; worthless as evidence, and
misleading if published as third-party traffic.

It is kept because it is the evidence for the fix: `origin` is now resolved per
request (`request_origin()` in `canarymaze/app.py`), and the operator's own
probes are counted as `selftest` and never folded into `organic`.

Contents: 4 mints, 7 requests, 1 sighting - all generated by the operator. No
third-party traffic, and no human was ever stored in it.

The live surface now writes to `ledgers/canary-public.sqlite3`.
